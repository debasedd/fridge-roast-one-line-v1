The program writes one line to `/output/entry.txt`:

**My smart fridge emailed me a photo of my own leftovers with the subject line: 'We need to talk.'**

A smart fridge with a camera and an app that emails you about your
leftovers — and opens with "We need to talk", like a
passive-aggressive partner. Specific to smart fridges, tight at 96
characters, and it dodges the obvious cracks about fridges ordering
groceries or watching you.

## Run it

```sh
python3 main.py
```
